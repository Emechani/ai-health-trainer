# PDF Korean font

NanumGothic-Regular.ttf is distributed under the SIL Open Font License 1.1.
The complete license and copyright notice are in OFL.txt.

Source: https://github.com/google/fonts/tree/main/ofl/nanumgothic

The font is embedded in weekly report PDFs so Windows and Linux servers produce
the same Korean text without relying on fonts installed on the host.
